# 数学内容与受限 Markdown 翻译设计

## 目标

织语需要在论文网页中同时满足两件事：模型能够读取公式以理解专业语境，页面上的原始公式又不能被当作自然语言翻译或破坏。译文允许使用规范 Markdown 和 LaTeX，但所有渲染必须在扩展本地完成，不执行模型返回的 HTML、脚本或远程资源。

## 方案选择

采用“结构化占位 + 原公式保留 + 本地渲染”。不采用只依赖提示词原样复写公式的方案，因为模型偶尔会改写转义符；也不采用克隆整段原 DOM 再逐文本节点替换的方案，因为不同站点的 MathJax、MathML 和 KaTeX 结构差异很大，容易破坏事件与布局。

## 数据流

1. 内容脚本按语义格式而非站点名识别 MathML、KaTeX、MathJax、`role="math"` 和常见 `data-tex` / `data-latex` 节点；arXiv 只是回归夹具之一。
2. 每个内联公式提取规范 LaTeX，并替换为稳定的 `⟦WEAVE_MATH_*⟧` 占位符；公式字典随翻译单元发送给模型，所以模型仍能利用公式理解上下文。
3. 独立块级公式及其编号不进入翻译队列，原网页公式保持不变；其 LaTeX 以只读 `contextMath` 关联到前后最近段落，使模型能理解“由上式”等引用。
4. 系统提示词要求输出严格 JSON，`text` 字段只允许受限 Markdown；每个已有公式占位符必须原样出现一次。
5. 响应解析器验证占位符。缺失、重复或伪造占位符会形成局部错误，不把损坏的内容插入页面。
6. 内容脚本使用 DOM API 渲染段落、标题、列表、引用、强调和代码；LaTeX 由本地 KaTeX 转为 MathML。禁止模型 HTML，禁止远程资源，KaTeX 使用 `trust: false` 和有限展开配置。

## 显示规则

- 内联公式保持在译文语句中，并继承当前译文主题。
- 块公式使用水平滚动的独立数学行，不挤压为逐字符竖排。
- 原页面已有块公式不重复渲染译文副本。
- KaTeX 无法解析时显示原始 LaTeX 文本，并标记为可读的降级状态，不阻断整批翻译。
- 原文、双语和仅译文模式仍然无损切换；停止翻译后删除全部织语节点并恢复页面。

## 适用边界

- 该流程按页面中的数学语义结构工作，因此同样适用于使用 MathML、KaTeX、MathJax、`role="math"` 或 LaTeX 数据属性的期刊、百科、课程与博客页面。
- 若公式只有图片、Canvas，或没有 LaTeX、MathML、无障碍文本的纯 SVG，首版保留原始视觉节点并避免破坏排版，但不会猜测公式内容；准确恢复这类公式需要后续 OCR 或视觉模型能力。

## 验证

- 单元测试覆盖 arXiv MathML、KaTeX、MathJax、语义数学节点、内联占位、块公式与公式编号排除、占位符完整性、Markdown 安全和 KaTeX 降级。
- 提供同时含内联与块级公式的 arXiv 风格 HTML 夹具。
- Playwright 验证块公式没有生成翻译节点、内联公式在译文中得到 MathML、没有横向页面溢出，原有网页与划词交互继续工作。
