# 原生 PDF + 翻译侧边栏（v0.5.0）

用户后续明确选择原生浏览器阅读，替代最初的独立阅读器方案。保留 Chrome PDF 查看器，PDF.js 只用于本地上下文解析和选区渲染。已完成的范围：选文右键进入 Chrome Side Panel、有限上下文、DeepSeek V4.1 / 通用视觉模型、独立任务路由和可控制缓存。

实现与验收清单：

- [x] 原生 PDF 阅读 + 浏览器侧边栏；真实右键菜单获取选文。
- [x] PDF 任务模型与视觉能力过滤、文字/自动/截图模式、受限输入预算。
- [x] 按页局部上下文与本地文本定位；按需生成指定页摘要，不上传全文。
- [x] 安全图片消息、受信侧边栏入口、取消与错误反馈、受限 Markdown/LaTeX 结果。
- [x] 默认会话图片缓存；可选 1/7/30 天磁盘缓存、容量上限、按文档/全部清除、最近截图复用。
- [x] 译文与摘要按完整请求身份缓存，不把本地缓存宣称为服务端图片记忆。
- [x] 最终全部回归：73 个 Vitest 通过，1 个可选本地 ASR 跳过；3 个无界面 E2E 通过；Windows 有界面原生菜单与截图 E2E 通过。

测试使用本仓库原创的文字/栅格公式 PDF 夹具和本地模拟模型端点；没有使用真实云端 Key，因此没有声称真实 DeepSeek 图像识别质量或任意论文版式已获验证。打包产物为 `.output/chrome-mv3` 和 `.output/weave-translate-0.5.0-chrome.zip`。

边界：不向 Chrome 内置 PDF 文字层注入；不绕过付费/认证文档权限；不运行 PDF JavaScript；图片预览确认后才发送。Token 预算为保守估计，不声称跨提供商精确计数。原 PDF 不修改、不自动持久保存。原生浏览器不暴露选区页码时，本地文字匹配定位；无法可靠定位时不附加邻近段落，用户可手动指定页码。本地文件需要用户关联一次。
